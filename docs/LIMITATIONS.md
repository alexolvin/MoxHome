# LIMITATIONS — что система не делает или делает приближённо

Ведётся с этапа E0. Всё, что система не делает или делает приближённо, — здесь, явно.

## Движок (epub-translator)

- `translate()` работает файл→файл; посегментного API нет. Выровненные пары «оригинал ↔ перевод»
  движок наружу не возвращает — выравнивание (E6) строится по измеренной разметке `APPEND_BLOCK`.
- Параметра исходного языка у движка нет — определение языка полностью на нашей стороне (L0).
- Возобновление — через кэш `LLM(cache_path=...)`, а не через состояние задания;
  поэтому кэш привязан к каталогу задания и не переиспользуется между заданиями с разной конфигурацией.

## Данные

- `wordfreq` — замороженный снимок частотностей ~2021 года; проект-источник данные не обновляет
  (дальнейшие обновления проектом не планируются — зафиксировано на L1). Для ранжирования лексики
  это приемлемо; для утверждений о «современной употребительности» — нет (ТЗ L1 п.3).
  API 3.1.1: `zipf_frequency(word, lang)` (wordlist-параметр снят; фактические списки —
  `large_*`/`small_*` msgpack по языкам), `frequency_of_word` удалена — измерено.

### CEFR-лексиконы: проверка наличия и лицензии (L1-7, проверка 2026-09-13)

ТЗ L1 п.4: агент обязан проверить фактическое наличие и лицензию лексиконов для всех пяти
языков; лексикон с неясной или запрещающей лицензией в поставку не включается (D6, Rule 2).
Исходники — GitHub (API), HuggingFace (API), PyPI; сайт Taalunie (NT2-WL) на дату проверки
недоступен (TLS-ошибка сертификата).

| Язык | Ресурс (найдено при проверке) | Лицензия | Включён в поставку | Фактический `cefr_source` |
|------|-------------------------------|----------|--------------------|---------------------------|
| en | Oxford 3000/5000 (канонический CEFR-список); TSV-зеркало GitHub `voothi/…-oxford-3000-5000` (метка MIT на репозиторий) | данные © Oxford University Press; MIT метаданных репозитория права на список не передаёт; лицензия на перепубликацию неясна | нет | `derived` |
| de | Goethe German 5000 (канонический CEFR-список); `ph98/german-cefr-wordlist` (частотности субтитров) | Goethe-Institut — некоммерческое образовательное использование (не открытая лицензия); ph98 — лицензия не указана (NOASSERTION) | нет | `derived` |
| fr | `FrancophonIA/CEFRLex` (HuggingFace, источник UZH multiCEFRLex); TAL-FR (CERCO 2007) | лицензия в карточке HF не указана; CERCO — условия не опубликованы | нет | `derived` |
| nl | NT2-WL (официальный CEFR-список для L2 нидерландского, Taalunie/Cito) | условия перепубликации машиночитаемой версии публично не подтверждены (сайт недоступен на дату проверки) | нет | `derived` |
| it | машиночитаемого CEFR-лексикона не найдено (GitHub/HF/PyPI) | — | нет | `derived` |

Последствия (честно): все пять языков — `derived`; уровень CEFR вычисляется из частотной полосы
+ оценки LLM, и в UI/артефактах везде, где он показывается, — **обязательная** метка
`Estimated CEFR level` (единая точка — `app.languages.cefr.label`, UI читает только её; L1-8).
CEFR никогда не подаётся как истина: влияет на отбор материала, но не блокирует его (ТЗ L1 п.4).

## NLP (заполняется по мере L0–L1)

Измерено на L1 (2026-09-13): модели 5/5 (`en_core_web_sm`, `de_core_news_sm`,
`fr_core_news_sm`, `nl_core_news_sm`, `it_core_news_sm`, все 3.8.0; spaCy 3.8.16).
Пайплайн — только нужные компоненты: токенизация + `tagger` + `attribute_ruler` (морфология)
+ `lemmatizer`; `parser`/`ner` отключены ради скорости (NLP нужен в L2 — включаются на этапе L2).

Точность лемматизации — эталонный набор 50 словоформ на язык
(`config/languages/<code>/lemma_reference.yaml`), по языкам (L1-2):

| Язык | Точность | Слабые формы (verbatim) |
|------|----------|-------------------------|
| en | 47/50 (94%) | drank→drank, swam→swam, higher→higher (сравнительные/редкие формы) |
| de | 47/50 (94%) | isst→isst, aß→aß, schlief→schlief (одиночные формы без контекста) |
| fr | 47/50 (94%) | parles→parle, viens→vien, fait→fait (lookup-лемматизатор слаб на спряжении) |
| it | 47/50 (94%) | mangiamo→mangare, vengo→vengare, sei→sei (lookup-лемматизатор даёт ложные основы) |
| nl | 47/50 (94%) | honden→honden, stoelen→stoelen, las→las (мн. число ряда существительных, präteritum las) |

Следствие: лемматизация надёжна на существительных/прилагательных/причастиях и большинстве
форм глаголов; для fr/it ряд форм спряжения остаётся слабым — S1 при отборе лексики
не обязан опираться на лемму глагола как единственный ключ (есть и `word_form`).

## Формат

- EPUB — статический формат. Интерактивный веб-ридер (перевод по клику, объяснение слова)
  не реализуется: отдельный этап после приёмки, не в объёме ТЗ.
- Адаптивное обучение (модель данных расширяемая) в первой версии не реализуется;
  соответствующие элементы UI отсутствуют или помечены `Not implemented`.

## NLP (заполняется по мере L0–L1)

- Точность лемматизации по языкам: ожидается высокой для de/fr/it/nl (обучаемые лемматизаторы),
  фактическая проверка — golden-набор 50 словоформ на язык (L1-2). До измерения — не утверждается.

## Среда

- Реальные LLM-прогоны (E5-8, V1.5/6/7/8/13) невозможны до предоставления эндпоинта (BLOCKER-1);
  до этого система разрабатывается и проверяется на детерминированном mock, статусы реальных
  прогонов не заявляются.
- V1.11 (доступ из tailnet с другой машины) требует вторую машину — без неё блок честно
  остаётся невыполненным.
