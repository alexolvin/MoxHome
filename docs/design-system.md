# Дизайн-система MoxMate (серия V)

Мобильный Web UI MoxMate (384×715, dsf 2.25, is_mobile, Android UA,
locale ru-RU). Дизайн-система серии V (ТЗ 2026-09-22): токены §4, компоненты
§6, экраны §2.8, светлая тема §4.2, удаление пояснений §9. **Тёмная тема — по
умолчанию; светлая — с V4.**

Система выросла из серии R (2026-09-20, база Primer) и серии V (2026-09-22):
V пересобрала токены под мобильный макет 384 px, сократила имена (префикс
`u3-` в токенах снят — он остался только у классов компонентов), перевела
кегли/сетку/радиусы на px и добавила светлую тему. Старые имена `--u3-*`
(D1/R1) не используются.

## 1. Темы

Тёмная — по умолчанию (`:root`). Светлая — `:root[data-theme="light"]`
(override поверх базовых токенов). Тема выбирается cookie `u3-theme` →
`data-theme` на `<html>` (inline JS в `base.html`, до первой отрисовки):

| `u3-theme` | Тема |
|---|---|
| (нет) / `dark` | Тёмная (default, `:root`) |
| `light` | Светлая (`:root[data-theme="light"]`) |
| `system` | Системная (`@media prefers-color-scheme:light` → light-override) |

Переключатель: «Настройки → Внешний вид» (Тёмная / Светлая / Системная).
**Цвета форматов (app.js) и градиенты заглушек обложек (css-books.css) — в
обеих темах одинаковые** (не переопределяются).

## 2. Токаны

### 2.1 Кегли (px, без rem)

| Токен | px | Где |
|---|---|---|
| `--f2` | 11 | мелкие подписи, метки |
| `--fx` | 12 | secondary, статусы, hint |
| `--fsm` | 13 | мелкие поля, чипы |
| `--fmd` | 14 | тело (базис) |
| `--fb` | 15 | кнопки, строки |
| `--flg` | 18 | h1/h2, крупные строки |
| `--fxl` | 22 | заголовок книги (исключение V-T6: S04/S05 ≤22) |
| `--fbr` | 24 | логотип-заглушка (S01 ≤24) |

Каждой кегли — ведущая `--l*` (+3–4 px). Критерий V-T6: `max_font_px` ≤20 на
всех экранах; S04/S05 ≤22; S01 ≤24.

### 2.2 Отступы / радиусы

Отступы: `--p:16px` `--g:12px` `--gs:8px` `--gx:4px`. Радиусы: `--r2:2px`
`--r6:6px` `--r8:8px` `--r10:10px` `--r12:12px` `--r16:16px` `--r24:24px`
`--r50:50%`.

### 2.3 Фиксированные размеры

`--u3-tap:44px` (тап-цель, V-T11); `--ch:36px` (радио-чип `.u3-rchip`);
`--chs:24px` (чип-тег); `--cpx:14px`; `--crw:40px`/`--crh:60px` (миниатюра
обложки); `--cpw:120px`/`--cph:180px` (обложка-заглушка); `--fh:48px`
(шапка); `--ah:40px`; `--ck:20px` (checkbox/radio).

### 2.4 Цвета форматов (`app.js` `EXPORT_COLORS`, не CSS)

| epub | pdf | docx | fb2 |
|---|---|---|---|

Используются в плитках экспорта/импорта (V3 §7.7); фон иконки — цвет + `2E`

### 2.5 Градиенты заглушек обложек (`css-books.css` `:root`)

Шесть градиентов `--cover-g1…--cover-g6` (160 deg) + `--cover-ph:rgba(255,255,255,.5)`

## 3. Шрифты

**Inter** (variable 100–900), две подложки: `inter-latin-wght-normal.woff2`
(латиница) + `inter-cyrillic-wght-normal.woff2` (кириллица) — `@font-face` в
`style.css`, `unicode-range` по подложкам. Моно — системный stack (`--fmo`).

## 4. Статусы (5 групп)

16 статусов → 5 групп (R1), цвет вторичен — статус несёт текст + глиф
(○ ◐ ✓ ! ✕):

| Группа | Статусы | Токен |
|---|---|---|
| Ожидание | CREATED, NEEDS_CONFIRMATION | `--st-w` |
| Работа | 8 рабочих (ANALYZING, TRANSLATING, …) | `--st-r` |
| Успех | COMPLETED | `--st-o` |
| Предупреждение | NEEDS_CONFIRMATION-adj, PARTIAL | `--st-a` |
| Ошибка | FAILED, CANCELLED, INTERRUPTED | `--st-e` |

`STATUS_GROUP` — единая таблица в `views.py`; классы `.status-wait/run/ok/
warn/err` + подложка чипа `--st-*-b`.

## 5. Контраст (V-T10)

Пороги (поправленный T13, ТЗ §10): основной текст ≥ 7:1; вторичный текст,
подписи на заливках кнопок/чипов, статусы ≥ 4,5:1; видимые линии/границы полей
≥ 3:1; декоративные рамки карточек не нормируются. `--ln` (< 3:1) — NOTE, в
гейт не входит (WCAG 1.4.11 не требует 3:1 для границ, не нужных для
идентификации компонента).

Проверка: `scripts/v10_contrast.py --theme dark|light` (пары «текст на фоне»
из токенов). **Обе темы PASS** (V4): худшие — light `--st-a`/`--st-ab` 4,75:1,
`--st-e`/`--st-eb` 4,71:1; dark `--st-w`/`--st-wb` 4,61:1.

## 6. Компоненты (классы `u3-*`, 81)

- **Кнопки** `.u3-btn` + `.u3-primary` (accent) / `.u3-danger` (err) /
  `.u3-text` / `.u3-tertiary`; `min-height:44px` (V-T11).
- **Карточки/панели** `.u3-card` / `.u3-panel` (surface-1, border `--ln`,
  radius `--r12`).
- **Чипы** `.u3-chip` (тег 24 px) / `.u3-rchip` (радио-чип 36 px, checked =
  `--acs`); зазор `≥8px` (поправленный T3).
- **Листы** `.u3-sheet-*` — bottom-sheet (`showModal`), открываются по клику
  (`data-sheet-open`), не по url (V3).
- **Статусы** `.u3-status` + `.status-*`; **пустое состояние** `.u3-empty`;
  **моно** `.u3-mono`; **ошибка/успех/предупр.** `.u3-err/.u3-ok/.u3-warn`.
- **Обложки** миниатюра `.u3-book-card` (40×60) + заглушка (градиент +
  буква); **иконки** `.u3-ico` (спрайт, 14/18/20/22).
