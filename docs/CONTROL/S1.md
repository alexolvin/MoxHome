# CONTROL — S1: отбор лексики

**Дата:** 2026-09-13 · **Ветка/PR:** `stage/S1` → `main`

Метод: стадия `LEARNING` (финальный рабочий этап, ТЗ_03) после `GLOSSARY_FIX`
(16 статусов; T-E3-2: 54/202 допустимых переходов 16×16) — learning-материалы
строятся по тексту перевода ПОСЛЕ L3. Стадия всегда существует: при
`learning_level=None` — no-op с отчётом (`learning_report.json`), предупреждения
— из `quality.json` (аналог L3.10; покрыто воркер-тестами E3/L3). Отбор
двухступенчатый (ТЗ S1.1, порядок обратный запрещён): **детерминированная
ступень** — пары выравнивания E6 → spaCy (модель пакета) → stopwords модели →
POS-фильтр `pos_select` (pack.yaml: данные, не код) → агрегация по лемме на всю
книгу (повторное вхождение — к существующему кандидату, S1.2) → Zipf-полоса
(wordfreq, L1.3) + CEFR (L1.4) → пре-ранк (частота, Zipf, лемма); **LLM-ступень**
— задача `vocabulary_card` (`prompts/vocabulary_card/v1.yaml`), по главам
батчами `limits.vocabulary_llm_batch` (25), никогда не вся книга (ТЗ общее
требование 5) — ранжирование по полезности и заполнение карточки. Перед выпуском
— обязательная детерминированная валидация каждой карточки (ТЗ S1.5): 1)
словоформа встречается в указанном сегменте (`contains_form` — тот же механизм,
что L2/L3, Rule 8); 2) лемма соответствует словоформе по spaCy; 3) карточка
валидна по `card_schema.json` языка (артикль de/nl, род fr/it, вспомогательный
глагол и пр. — обязательные поля по POS из схемы, Rule 8) + плейсхолдеры (Rule 5);
4) пример из книги (текст главы) либо помечен `example_generated`; 5) лемма
среди детерминированных кандидатов («призрак» отклоняется). Отклонённые не
исчезают: `vocabulary_cards.json` → `rejected` с причинами + предупреждение в
`quality.json`. Плотность: `max_cards = floor(N × W / 1000)` (N =
`limits.vocabulary_max_cards_per_1000_words` = 15.0, W — слова выровненного
подмножества E6), фактическая плотность измеряется и записывается. Карточка
привязана к источнику и версии (ТЗ общие требования 1–2): `chapter_id`,
`segment_id`, `source_text_hash`, `prompt_file`/`prompt_version`, `model`,
`profile`, `source_language`/`target_language`, `user_level`/`user_cefr`,
`glossary_hash`, `timestamp`. CEFR-диапазон пользователя — НЕ абсолютный
фильтр: карточка с `|CEFR − user| ≥ limits.cefr_out_of_range_distance` (2)
выпускается с меткой `cefr_out_of_range=true`. Идемпотентность подстадии —
собственный ключ `stage_results: "s1_vocabulary" = sha256(input_hash |
glossary_hash | level | cefr)` (learning-параметры НЕ в `config_hash` — перевод
от них не зависит). `quality.json` → секция `s1`: `book_words`, `max_cards`,
`candidates`, `issued`, `rejected`, `not_selected`, `missing`,
`book_example_share`, `density_actual`. LLM — mock-сервер (D3, rot3 +
POS-поля по лемме); реальные LLM-прогоны не проводились (BLOCKER-1).
Прогон — `python tests/s1_evidence.py`, тесты — `pytest
tests/test_s1_vocabulary.py` (14: T-S1-1…T-S1-10, T-S1-7 ×5 языков).
Verbatim-захваты: `docs/CONTROL/evidence/S1/s1-1…s1-7*.txt`.

## Метрики и механизмы (измерено vs не проверено)

**Измерено** (артефакты в колонке «Артефакт»):
- 0 выпущенных со словоформой вне сегмента (24/24) — S1-1;
- 0 дублей леммы; POS-поля языка (артикль) — 100% в enum (de 27/27, nl 22/22)
  — S1-2;
- плотность: cap=27, issued=24, density_actual=13.165112 ≤ 15.0, записано —
  S1-3;
- плейсхолдер → отклонён с причиной; 23/23 выпущенных валидны по схеме языка —
  S1-4;
- воспроизводимость 100% (два запуска); «призрак» отклонён и не выпущен — S1-5;
- примеры из книги 0.9583 ≥ 0.95; сгенерированный — только с пометкой — S1-6;
- 5/5 исходных языков до LEARNING с метриками — S1-7.

**Не проверено / ограничения (честно):**
- LLM-заполнение — mock (D3): реальные LLM-прогоны не проводились (BLOCKER-1).
  Проверены реальные механизмы: детерминированный отбор, 5-пунктная валидация,
  дедупликация, плотность, ранжирование, отчётность; LLM в mock —
  детерминированное заполнение (rot3 + POS-поля по лемме) и инъекции
  (placeholder/ghost/generated example).
- `cefr_level` у всех пяти языков — вычисленный: `cefr_source: derived`
  (L1.4, лексиконы не в поставке — лицензии), `cefr_level` = частотная полоса
  (L1-9), `cefr_source="derived"` на карточке; «не подан как истина».
  `cefr_out_of_range` измеряется по этому уровню (user A1, дистанция ≥ 2).
- wordfreq — замороженный снимок (~2021, L1.3): слово вне базы → `zipf=0.0` →
  полоса A1 (оценка, не истина; зафиксировано в docs/LIMITATIONS.md).
- Служебные слова — `is_stop` модели (данные модели, не хардкод): измерено, что
  в en_core_web_sm «go» — stopword (исключается из кандидатов); список слов
  синтетических книг подобран с учётом этого.
- fr_core_news_sm не имеет компонента `tagger` (L1-1): POS дают
  `morphologizer` — кандидаты ненулевые в 5/5 языках (измерено 2026-09-13).
- Плотность — `floor`: у книг < ~67 слов cap=0 (0 карточек) — семантика
  «не более N на 1000 слов»; метрики при этом записаны (S1-7, de/fr/it/nl
  фикстуры).
- no-op-путь (learning не включён) — покрыт воркер-тестами E3/L3 (LEARNING
  завершается COMPLETED/CWW по предупреждениям quality.json); отдельного
  S1-теста нет (повторный механизм L3.10).
- Идиоматичность/контекстная значимость в ранжировании (ТЗ S1.2) — на
  LLM-ступени; в mock-мире usefulness = f(лемма) (детерминированно), реальные
  веса значимости не измерялись (BLOCKER-1).
