## Протокол фазы (время — UTC; `date -u`)

- 2026-09-28 — ветка `stage/mtpe-M5` с `main` (после merge M4 `0787a89`); D131
  (решение о писателе) — первым коммитом этапа, до кода.
- **Писатель** (`app/mtpe/writer.py`, §4.9): вход — исходный EPUB + `segments.jsonl` +
  `final.jsonl` + `SubmitKind`. `read_epub` (тракт A) даёт главы/сегменты (Rule 8:
  сегментацию не дублируем). `segment_id → элемент` — той же формулой, что ридер
  (`make_segment_id`). Группировка по **text-root**: двойная сегментация контейнера
  (`blockquote` + внутренний `p`) → **один** переводный блок, берётся финал листового
  сегмента (блок == text-root). **Вставка текста**: `_tokenize` разбивает `final.text`
  на `('text', s) | ('open'/'void'/'close', n)`; текст — `_append_text` (`.text`/`.tail`,
  lxml экранирует `<`/`>`/`&`), элементы — `_make_element(markup_map[n][0])` (trusted-тег
  исходника, **XHTML-разбор ответа не делается**). **void-правило (D132)**: из перевода
  несутся только элементы с текстом и `<br>`; нетекстовые пустые (`img`, `wbr`, …)
  пропускаются (движок в переводе их не несёт — иначе M5-2 расходится на блоке с `<img>`).
- **Вставка/замена** (по `SubmitKind`): APPEND_BLOCK — клоновка `Element(tag, attribs)` +
  вставка sibling (tail оригинала → переводу); REPLACE — замена контента text-root на
  месте (тег/id/XPath хранятся, суффикса нет). **id-дедуп** document-wide (APPEND_BLOCK):
  1-е хранит, 2-е → `id__translated`, 3-е → `id__translated_2` (и блок, и inline-якоря).
- **Выход**: `rebuild_epub(source, patches, .partial)` (mimetype первой без сжатия,
  остальное — побайто) → `atomic_finalize(.partial, target, settings)` (валидация +
  EPUBCheck fail-closed + бэкап + `os.replace` + fsync). Запись `write_map.json`
  (`segment_id` → XPath блока перевода) — для M5-4.
- **Эталон «тракт T»** (M5-2/M5-3): `EpubTranslatorEngine(settings, job_dir).translate_book
  (TranslationRequest(source, target, target_language="ru", mode=APPEND_BLOCK))` под тем же
  mock (движок отвечает rot3; `epub-translator 0.1.10` установлен). Свёрка — парсинг
  деревьев (никогда не байты: движок меняет порядок атрибутов/namespace/self-closing).
- **Скелет M5-2**: `qc._diff_trees(m_root, t_root, "/", doc, ignore_text=True)` по spine +
  OPF + nav; атрибуты языка нормализованы (двинок при ресериализации «схлопывает» `lang`+
  `xml:lang` в `xml:lang` и убирает корневой `lang` — сериализационный артефакт, не
  структура). nsmap не сравнивается (это сериализационная деталь, см. docstring `_diff_trees`).
- **M5-4**: штатный E6 (`aligner.build_alignment_report`, `submit_mode=APPEND_BLOCK`,
  `block_tags`/`min_coverage`/`identical_whitelist` из конфига) — `translation_xpath` каждой
  пары == `write_map.json`; идентичные переводы (== исходник) E6 помечает `identical`
  (вне `aligned`), поэтому эталонный прогон — mock `ok` (final ≠ исходник).
- Тесты: `tests/test_mtpe_m5.py` (6 функций / 10 кейсов). M5-1 — полный тракт M (черновик
  M3 + постредактура M4 + писатель) на 5 книгах под mock. M5-5/M5-7 — изолированные
  проверки писателя (контрольный ввод / monkeypatch `os.replace`), без LLM. M5-2/M5-3 —
  сравнение с **реальным** выходом движка. M5-6 — `git diff` по модулям (CONTROL).
- Регрессия: ruff 0 / mypy 0 (94) / **pytest 494** (база 484 + 10, ни один прежний
  не удалён).
