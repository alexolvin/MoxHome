# CONTROL — S2: устойчивые выражения и MWE

**Дата:** 2026-09-13 · **Ветка/PR:** `stage/S2` → `main`

Метод: подстадия `s2_mwe` стадии `LEARNING` (ТЗ_03, после S1) — материалы
строятся по тексту языка-ИСТОЧНИКА (подмножество E6, исходные пары — как S1).
Гейт уровней (ТЗ_03, таблица): S2 входит в `Learning`/`Intensive`
(`SUBSTAGE_LEVELS`, данные `app/learning/__init__.py`); на `Minimal`/`Balanced`
подстадия не исполняется и артефактов не выпускает. Идемпотентность —
собственный ключ `stage_results: "s2_mwe" = sha256(input_hash |
glossary_hash | level | cefr)` (та же формула, что у `s1_vocabulary`).

Типы конструкций и их шаблоны — **данные таксономии** (Rule 1):
необязательное поле `patterns` в `config/languages/<code>/phenomena.yaml`
(валидация `app/languages/phenomena.py`: неизвестный тип/поле — ошибка,
опечатка не отключает шаблон молча, Rule 6). Три механизма:
`sequence` — смежная POS-последовательность 2–3 позиции, опционально
разрешённые словоформы позиций (без регистра); `wrap` — два маркера в пределах
одного предложения (start раньше end; `end_final` — end последним
содержательным токеном; один хит на предложение); `separable_units` — механизм
L1 `lexical_units` (отделяемые приставки — данные pack.yaml, Rule 8: один
механизм, измерен T-L1-11). `min_occurrences` (данные) — жёсткий фильтр
повторяемости кандидата на всю книгу; применяется только к широким
POS-последовательностям (специфические `separable`/`wrap` — без фильтра).
Явление БЕЗ `patterns` детерминированно не отбирается — честный предел
механизма (EN-IDIOM, DE-FESTE-WENDUNG, FR-EXPRESSION-IDIOMATIQUE,
IT-ESPRESSIONE-IDIOMATICA, NL-VASTE-UITDRUKKING). Обязательные
языкоспецифичные типы ТЗ_03 S2.2 все имеют шаблоны: de DE-TRENNBAR
(separable) + DE-NOMEN-VERB-VERBINDUNG (NOUN VERB, min_occ 2); nl
NL-SCHEIDBAAR (separable) + NL-ER-CONSTRUCTIE (ADV/PRON «er» + VERB); fr
FR-NEGATION-COMPLEXE (wrap ne/n' → jamais/plus/rien/personne) +
FR-LOCUTION-VERBALE (PRON-клитика + VERB, min_occ 2); it
IT-PRONOMI-COMBINATI (PRON PRON VERB) + IT-VERBI-PRONOMINALI (PRON VERB) +
IT-VERBI-SINTAGMATICI (VERB ADP); en EN-PHRASAL-VERB (VERB+ADP/ADV частицы,
min_occ 2) + EN-COLLOCATION (ADJ NOUN / VERB DET NOUN, min_occ 2).

Детерминированный предотбор (`app/learning/mwe.py`): `mwe_hits` (по парам
E6, порядок карты выравнивания — воспроизводимость S2-5) →
`select_mwe_candidates` (агрегация: отделяемые — по (id, unit_lemma),
прочие — по (id, нормализованная поверхность, pack-normalization);
повторное вхождение — к существующему кандидату; детерминированный порядок
(−вхождения, id, поверхность)). Поверхностная форма пролёта — из ИСХОДНОГО
текста по позициям символов (слипшиеся формы fr «n'est»/«s'appelle» остаются
слитными, как в тексте книги). LLM — задача `mwe_note`
(`prompts/mwe_note/v1.yaml`), по главам батчами `limits.mwe_llm_batch` (25),
никогда не вся книга (ТЗ общее требование 5); модель ТОЛЬКО объясняет
(значение, перевод, канонический вид) — выдвижение запрещено (ТЗ S2.3).
Перед выпуском — 5-пунктная детерминированная валидация
(`check_mwe_records`, S2.6 + S2.5 + S1.5): 1) id типа ∈ таксономии языка
(S2-1); 2) поверхность — среди детерминированных кандидатов («подброшенное»
отклоняется, механизм S1.5); 3) ВСЕ части конструкции — в указанном сегменте
(`contains_form`, Rule 8; S2-3); 4) отделяемая конструкция — обе части с
позициями (S2-2/S2-5); 5) канонический вид непуст. Отклонённые не исчезают:
`mwe_records.json` → `rejected` с причинами + предупреждение в `quality.json`.
Плотности/лимита количества записей в ТЗ S2 нет. Запись (ТЗ S2.4 + общие
требования 1–2): `surface`, `parts` (текст + позиция в предложении),
`canonical`, `phenomenon_id`, `meaning`, `translation`, `unit_lemma`
(отделяемые), `occurrences`, `chapter_id`, `segment_id`, `segment_ids`,
`source_text_hash`, `example_sentence`, `source_language`/`target_language`,
`user_level`/`user_cefr`, `glossary_hash`, `prompt_file`/`prompt_version`,
`model`, `profile`, `timestamp`. `quality.json` → секция `s2`: `enabled`,
`book_words`, `candidates`, `issued`, `rejected`, `separable`, `report`.
Полнота/точность (S2-2/S2-4) — на golden-наборах
`config/languages/*/mwe_golden.yaml` (de/nl 30, fr 14, en 12, it 12
предложений; 84 пары «предложение → ожидаемый id») по ПРЕДОТБОРУ:
сопоставление пар (предложение, id типа) — по id, НЕ по unit_lemma (конвенция
L1-11: ожидаемая unit — по стандартной грамматике, точность unit_lemma —
отдельный справочный показатель `golden_unit_accuracy`). LLM — mock-сервер
(D3, эхо кандидатов + rot3; сценарий `mwe_bad_id` — инъекция id вне
таксономии); реальные LLM-прогоны не проводились (BLOCKER-1). Прогон —
`python tests/s2_evidence.py`, тесты — `pytest tests/test_s2_mwe.py`
(17: T-S2-1…T-S2-7, T-S2-4 ×5 и T-S2-6 ×5 языков). Verbatim-захваты:
`docs/CONTROL/evidence/S2/s2-1…s2-6*.txt`.

## Метрики и механизмы (измерено vs не проверено)

**Измерено** (артефакты в колонке «Артефакт»):
- 0 принятых с id вне таксономии; отклонение с причиной — S2-1;
- recall de 1.000 / nl 1.000 ≥ 0.85 на golden-30; 0 записей без второй
  части (движок 30/30 и сквозно 2/2 + 2/2) — S2-2;
- 0 частей вне сегмента (7/7 verbatim); подброшенная часть отклонена — S2-3;
- precision 1.000 на всех 5 языках (84 пары, ложных 0) ≥ 0.80 — S2-4;
- воспроизводимость 100% (движок и сквозной) — S2-5;
- 5/5 исходных языков до LEARNING с метриками S2 — S2-6.

**Не проверено / ограничения (честно):**
- LLM-объяснение — mock (D3): реальные LLM-прогоны не проводились
  (BLOCKER-1). Реальные механизмы: детерминированный предотбор (шаблоны +
  повторяемость), 5-пунктная валидация, дедупликация по поверхности,
  метрики golden, отчётность; mock — детерминированный эхо + rot3 и
  инъекция `mwe_bad_id`.
- Синтаксического парсера/зависимостей в механизме НЕТ: только
  POS-последовательности (2–3 позиции), wrap-маркеры и `lexical_units`.
  DE-NOMEN-VERB-VERBINDUNG детектируется в повёрнутом порядке
  «Nomen + глагол» (NOUN смежно VERB, измерено); «Er trifft eine
  Entscheidung» (VERB DET NOUN) шаблоном не покрывается — честный предел.
- Точность `unit_lemma` — справочный показатель (L1-11): nl 20/30 (модель
  хранит финитную форму: tikkt→«wegtikkt», keert→«omterugkeren» и др.);
  recall/precision от unit_lemma НЕ зависят (сопоставление по id типа).
- Слипшиеся формы (fr elision) — поверхности берутся из исходного текста по
  позициям символов; «n'est jamais venu»/«s'appelle» — verbatim (измерено,
  fr golden 14/14).
- it-комбинаты со вспомогательным глаголом («Ce l'ho detto»: PRON PRON AUX
  VERB) шаблоном [PRON, PRON, VERB] не покрываются — честно зафиксировано в
  `it/phenomena.yaml`; IT-VERBI-SINTAGMATICI — только VERB+ADP.
- Идиоматические типы без `patterns` (EN-IDIOM, DE-FESTE-WENDUNG,
  FR-EXPRESSION-IDIOMATIQUE, IT-ESPRESSIONE-IDIOMATICA,
  NL-VASTE-UITDRUKKING) детерминированно не отбираются — только LLM-метки
  при прочих записях; полный детект идиом вне скоупа механизма (честный
  предел).
- Омонимия POS модели (измерено при подборе golden): fr «téléphone» (verb) →
  NOUN; it «ricordo» → NOUN; nl «doofd»/«zacht»/«licht» → NOUN/ADJ —
  golden-предложения подобраны по факту разметки модели (проверено прогоном).
- Малые фикстуры (23–24 слова) → 0 кандидатов: warning-семантика («S2: MWE-
  кандидаты не отобраны (0) — записей нет»), не ошибка (S2-6).
- `min_occurrences` — данные шаблона (de/en/fr/it широкие = 2); nl
  NL-ER-CONSTRUCTIE без фильтра (формальное «Er» sentence-initial = ADV,
  измерено; внутрипредложное er не смежно глаголу из-за V2).
- no-op (learning не включён) и гейт уровней покрыт T-S2-7 (Minimal — ни S1,
  ни S2; Balanced — S1 без S2; Learning — оба) и воркер-тестами E3/L3.
