имена без `.epub` не валидирует — на чистой фикстуре (bilingual.epub):
```

```

доказательств завершения (D82) = записанное «0/0». Т.е. EPUBCheck в конвейере
до фиксов реально не исполнялся; все записанные «0 ошибок» (V1.13, прогон 1
V1R.5) — результат отказа валидатора. Гипотеза краша JVM отклонена: механизм
воспроизведён детерминированно. job.log 19:44:49.730Z «EPUBCheck v5.3.0: 0
fatal, 0 error, 0 warning» — единственный согласующийся с кодом путь.
