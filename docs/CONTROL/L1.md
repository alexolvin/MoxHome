# CONTROL — L1: языковые пакеты (NLP, таксономия, карточки, CEFR, частотность)

**Дата:** 2026-09-13 · **Ветка/PR:** `stage/L1` → `main`

Метод: данные языка — `config/languages/<code>/pack.yaml` + `phenomena.yaml` +
`card_schema.json` + `golden.yaml` + `lemma_reference.yaml` (Rule 1: языка нет в
коде, каталог обнаруживается). NLP — spaCy 3.8.16, модели 5×3.8.0
(`en_core_web_sm`, `de_core_news_sm`, `fr_core_news_sm`, `nl_core_news_sm`,
`it_core_news_sm`), пайплайн — только нужные компоненты: токенизация +
`sentencizer` (добавляется, без него `doc.sents` = E030 — измерено) + `tagger` +
`attribute_ruler`/`morphologizer` (морфология) + `lemmatizer`; `parser`/`ner`
отключены (включаются в L2 — NER понадобится). Загрузка — один раз на процесс
(класс-держатель); версии фиксируются здесь и в отчёте каждого задания
(`nlp_report` — секция `nlp` в `validation.json`/`plan.json`, значения — из
`importlib.metadata`, без загрузки пайплайна). Частотность — `wordfreq` 3.1.1
(`zipf_frequency(word, lang)`; wordlist-параметр снят — измерено) + полосы
через Zipf-шкалу, границы — только в `pack.yaml` (L1-9). CEFR: аудит наличия и
лицензии для всех пяти языков (2026-09-13, GitHub API/HuggingFace API/PyPI) —
чистого машиночитаемого лексикона нет, все 5 → `derived` (таблица verbatim —
`docs/LIMITATIONS.md`, L1-7); derived → обязательная метка `Estimated CEFR level`
(единая точка `cefr.label`). Таксономия явлений — per-language id, id вне
таксономии = ошибка валидации, артефакт отклоняется (L1-6). Карточки —
JSON-схема (draft 2020-12) на язык, обязательные поля зависят от языка и части
речи; без обязательного — отклонение + QC-счётчик; плейсхолдер «—» вместо
значения — отдельная проверка (Rule 5). Отделяемые глаголы (de/nl) —
детерминированные правила на POS-разметке, приставки — данные `pack.yaml`
(`separable_prefixes`); финитность головы: ранее в предложении есть другой
глагол без границы клизмы (CCONJ/SCONJ/PUNCT) — текущий не финитный (измерено:
nl-модель размечает наречие «vroeg» как VERB «vragen» — без правила ложная
единица «opvragen»). Отсутствие модели — отказ резолвера (L0), не исключение
в середине задания. Прогон — `python tests/l1_evidence.py`, тесты —
`pytest tests/test_l1_packages.py` (27 запусков). Verbatim-захваты:
`docs/CONTROL/evidence/L1/l1-1…l1-12_*.txt`.

## Метрики и механизмы (измерено vs не проверено)

**Измерено** (артефакты в колонке «Артефакт»):
- 5/5 пайплайнов, версии 5×3.8.0 + spaCy 3.8.16, один раз на процесс (L1-1);
- лемматизация 47/50 (94%) на каждый из 5 языков, слабые формы verbatim (L1-2);
- карточки: без обязательного поля 0 выпущенных (de/nl/fr/it, L1-3..5),
  плейсхолдер «—» — 0 (Rule 5), `null` nullable-полей — легитимен;
- таксономии 11/12/9/9/9, чужой id — 0 принятых (L1-6);
- CEFR-аудит 5/5 строк, все языки `derived`, 0 лексиконов в поставке (L1-7);
- метка `Estimated CEFR level` — все 5 языков, единая точка `cefr.label` (L1-8);
- полосы: границы только в `pack.yaml`, в коде 0 числовых порогов (L1-9);
- golden 20×5, покрытие таксономии 100% (11/11, 12/12, 9/9, 9/9, 9/9),
  чужой id отклоняется (T-L1-10);
- отделяемые глаголы: 1 единица на «Er steht früh auf» (aufstehen) и
  «Hij staat vroeg op» (opstaan), предлоги-FP 0 (T-L1-11);
- удаление лексикона: derived-переход, метка меняется, 0 исключений,
  резолвер перечисляет (T-L1-12).

**Не проверено / честно:**
- UI (U1) ещё не построен: L1-8 доказан на уровне единственной функции
  `cefr.label`, из которой UI обязан читать метку (Rule 8) — «100% мест
  отображения» обеспечено единством точки, а не измерено на рендере;
- `lexical_units` детектирует только главную конструкцию с приставкой справа
  от глагола (придаточные, начальная позиция «Aufstehen ist…» — не
  детектируются); правило финитности головы — эвристика на POS (без парсера),
  измерена на зафиксированных FP-сценариях (nl «vroeg» как VERB, de «auf der
  Bank», nl «naar huis»);
- L1-1 фиксирует версии в отчёте задания через `importlib.metadata` (без
  загрузки пайплайна — лёгкий путь для `validation.json`/`plan.json`);
  фактическая загрузка с верификацией компонентов — в evidence (L1-1) и в
  точке использования (`load_nlp`);
- качество Zipf-значений `wordfreq` 3.1.1 (снимок ~2021, wordlist-параметр
  снят — «best»): приемлемо для ранжирования полос, нет — для утверждений о
  современной употребительности (LIMITATIONS);
- лемматизация fr/it слаба на ряде форм спряжения (parles→parle,
  mangiamo→mangare — verbatim в L1-2): S1 при отборе лексики не обязан
  опираться на лемму глагола как единственный ключ (есть `word_form`).
