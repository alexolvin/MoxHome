## Дополнительные измеренные факты (за рамками порогов)

- **Ключ кэша не включает модель:** прогон D (`model=other-model`, тот же кэш) — 0 токенов / 0 вызовов
  (D/A = 0.00%). Ключ = `sha512(messages + f"{версия}:{target_language}")`.
  Следствие (D15): адаптер E5 обязан изолировать кэш-папку по модели.
- **Повторы:** цикл движка повторяет только `openai.Timeout`, `APIConnectionError`,
  httpx Stream/Network/Protocol, HTTP 502/503/504; простой HTTP 500 — немедленный `raise`.
  Клиент `OpenAI(...)` создаётся без `max_retries` → встроенные ретраи SDK (дефолт 2)
  складываются с циклом движка.
- **Fill-повторы:** `range(max_retries)` вызовов + финальное событие
  `over_maximum_retries=True`; при исчерпании перевод группы отбрасывается,
  исходный контент остаётся, книга доводится до конца (`progress` → 1.0).
- **Вся книга — один поток:** 1 translate-запрос + 1 fill на фикстуру (группа < 2600 токенов);
  TOC-ссылки и `dc:title/creator/description/subject` переводятся, `dc:language/identifier/date`
  — нет; `h1` внутри nav в поток не входит.
- **Ресериализация** XHTML/OPF/OPF-метаданных: побайтовая идентичность с исходником
  не сохраняется никогда (порядок атрибутов, namespace, self-closing) — QC сравнивает
  текстовое содержимое, а не байты.
