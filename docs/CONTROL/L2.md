# CONTROL — L2: глоссарий и терминология

**Дата:** 2026-09-13 · **Ветка/PR:** `stage/L2` → `main`

Метод: глоссарий книги строится до перевода (`app/glossary/`, `app/domain/glossary.py`):
кандидаты — детерминированные правила (5, `RULE_PRIORITY`: NER, многословные
последовательности, аббревиатуры, единицы измерения, слова с заглавной вне
начала предложения; дедупликация NFC+casefold, каноническая поверхность — самая
частотная; порог `glossary.min_occurrences=2`), LLM привлекается только для
перевода и пояснения отобранных кандидатов (задача `glossary_annotation`,
fail-closed: отсутствующий/некорректный элемент — `GlossaryError`). Для
флективного `ru` (`inflected: true`, 12 форм: 6 падежей × ед./мн. ч.) к записи
генерируется парадигма целевой формы и детерминированно проверяется
(`check_paradigm`: число форм = числу имён, нет пустых, каждое совпадение имён
форм объяснено, общая основа ≥1 символа); непрошедшая — отклоняется, термин
`paradigm_unverified` (исключается из автоправки L3), несклоняемые помечаются
явно (`not_applicable`), а не получают 12 идентичных форм. Стилевой профиль
книги — один раз (`book_style`, `neutral`/`formal`/…), хранится с книгой,
подставляется в `user_prompt` перед глоссарием (учитывается в том же лимите).
Глоссарий → тракт T через `user_prompt` (`build_glossary_prompt`): лимит —
`limits.glossary_max_user_prompt_chars` (конфигурация), при превышении термины
отбираются по числу вхождений, факт усечения (число отброшенных) — в
`translation_result.json` и QC-предупреждении, не молча. После перевода —
проверка согласованности на выравнивании E6 (`check_consistency`): термин
присутствует в источнике сегмента (NFC+casefold, граница слова), согласованно —
если в переводе сегмента есть каноническая форма или форма **проверенной**
парадигмы; расхождение — запись с вариантами и `segment_id`
(`glossary_consistency.json` + секция `quality.json`), порог
`consistency_min_share=0.95` — предупреждение «L2: …», **текст L2 не правит**
(L3 — отдельный этап). Глоссарий и стиль — в хранилище книги
`books/<book_key>/<source_hash>/` (D53): версия = sha256 исходного файла, при
новом хэше старые версии помечаются `superseded`. NER включён (D59,
`parser`/`ner` — единственные новые компоненты поверх L1). Функция opt-in:
`glossary.enabled` по умолчанию `false` (D60), в прогонах L2 включена.
LLM — mock-сервер (D3, детерминированный rot3; сценарий
`glossary_inconsistent` внедряет неканонический перевод «Xrongy» вместо
rot3(Wexley)=«Zhaohb»). Proгон — `python tests/l2_evidence.py`, тесты —
`pytest tests/test_l2_glossary.py` (11). Verbatim-захваты:
`docs/CONTROL/evidence/L2/l2-1…l2-8*.txt`.

## Метрики и механизмы (измерено vs не проверено)

**Измерено** (артефакты в колонке «Артефакт»):
- воспроизводимость кандидатов 100% (13/13, побайтово) — L2-1;
- de: 0 ложных capitalized-кандидатов, контрфакт — 2 (L2-2);
- внедрённая несогласованность: 3/3 детекция, 0 правок текста
  (хэши источника и target.epub на границах этапов — verbatim) — L2-3;
- согласованность complex en→ru: 46/46 = 100.0% ≥ 95% (L2-4);
- усечение: 4/13 включено, 9 отброшено, предупреждение (L2-5);
- парадигмы ru: 9/10 = 90.0% ≥ 90%, остальные `paradigm_unverified`
  с причиной (L2-6);
- golden-30: 0 ложных расхождений с парадигмой / 20 без (контроль);
  «Marlow» 20× → 1 вариант (L2-7);
- 5 исходных языков → ru: 5/5 (L2-8);
- версионность (T-L2-9): новый хэш → v1 `superseded`, v2 `current`;
  глоссарии v1/v2 различаются и не подменяют друг друга;
- 6 падежей одного имени без парадигмы-шума (T-L2-10): 0 расхождений,
  варианты = ровно 6 падежных форм (casefold);
- несклоняемый термин (T-L2-11): `not_applicable`, `inflected=false`,
  `forms=()` — 12 идентичных форм не порождаются.

**Не проверено / честно:**
- **реальные LLM-прогоны не проводились** (BLOCKER-1): LLM — mock (rot3).
  Детерминированность списка кандидатов (L2-1) и механика проверки
  (L2-3..7) от модели не зависят; качество реальных переводов терминов,
  пояснений и парадигм — не проверено;
- mock-парадигмы — псевдорусские (rot3 + суффиксы): проверена механика
  `check_paradigm` (число форм, различимость, объяснённые совпадения, общая
  основа), а не реальная морфология; реальная морфология покрыта golden-30
  (ручные формы, L2-7);
- **шум NER (sm-модели) измерён**: кандидаты `first`, `fox`, `Second` в
  complex.epub — ложные сущности (например `fox`→ORG). На критериях не
  сказывается (воспроизводимость и детекция держатся), но реальный LLM на
  этапе аннотации получает и такие кандидаты (mock их «переводит»
  эхо-ответом); отсев мусорных кандидатов — за LLM-пояснением/отказом,
  механикой правил не обеспечивается;
- **нет word-level выравнивания**: проверка presence-based (есть ли в переводе
  сегмента каноническая/парадигматическая форма). Два варианта в одном
  сегменте не детектируются; «разные переводы одного термина» измеряется
  различием вариантов между сегментами (L2-3, L2-7) — осознанное упрощение
  (E6 даёт сегментное выравнивание, L3.2 — presence-контракт);
- `book_key` = имя файла: две разные книги с одинаковым именем файла
  столкнутся в хранилище (задокументировано, не решено — имя+хэш достаточно
  для текущих прогонов);
- в mock-мире финальный текст перевода идёт через FILL-путь движка
  (code() сдвигает и буквы XML-тегов → ответ translate структурно невалиден,
  движок переключается на fill); детекция — по финальному тексту, так что
  критерии не зависят от пути;
- короткие синтетические книги проходят L0.5 `NEEDS_CONFIRMATION`
  (уверенность определителя) — подтверждаются известным исходным языком
  тем же путём, что воркер (переход + `confirm_job`).

## Тесты (11 запусков, `pytest tests/test_l2_glossary.py`)

- T-L2-1: воспроизводимость кандидатов (complex, 2 запуска — идентичны);
- T-L2-2: de — правило «с заглавной» выключено в `pack.yaml` (атрибут `False`;
  lang_de 0, de_repeat 0 capitalized; контрфакт — {'Mühle', 'Fluss'} ⊆ поверхностей);
- T-L2-3: внедрённая несогласованность: 3/3, share=0.0, «Xrongy»×3 /
  «Zhaohb»×0 в target.epub, хэши источника и target.epub неизменны, предупреждение;
- T-L2-4: share ≥ 0.95, 0 предупреждений L2; глоссарий в store по хэшу версии
  (13 терминов, `current`);
- T-L2-5: усечение (лимит 200): `kept+dropped=total`, `dropped>0`,
  `truncated=true`, `prompt_chars ≤ limit`, предупреждение «user_prompt усечён»;
- T-L2-6: 9/10 verified (≥90%), Badparadigm `unverified` с причиной «объясн…»,
  Indeclinable вне знаменателя;
- T-L2-7: golden-30 — 0/30 с парадигмой, 20/30 без (контроль); marlow 20× →
  20/20, 1 вариант, `occurrences=20` в глоссарии;
- T-L2-8: 5 книг → ru: 5/5, target.epub + глоссарий версии на каждую;
- T-L2-9: изменение исходного файла: хэши различаются, v1 `superseded` /
  v2 `current`, глоссарий v1 ≠ v2 (Brno vs Ostrava), новый прогон использует v2;
- T-L2-10: 5 имён × 6 падежей ед. ч. — 0 расхождений; по 6 вхождений каждое,
  варианты = ровно 6 падежных форм (casefold);
- T-L2-11: Indeclinable — `not_applicable`, `inflected=false`, `forms=()`;
  парадигма с идентичными формами не помечается `verified` (Badparadigm).
