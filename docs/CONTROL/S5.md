# CONTROL — S5: сборка learning EPUB и экспорт карточек

**Дата:** 2026-09-14 · **Ветка/PR:** `stage/S5` → `main`

Метод: подстадия стадии `LEARNING` — `s5_assembly` (ТЗ_03, после S4) —
исполняется на ВСЕХ ЧЕТЫРЁХ уровнях (`Minimal`…`Intensive`): состав
секций определяет наличие артефактов вышестоящих стадий (T-S5-10: у
Minimal в книге нет секций лексики/грамматики/вопросов — но книга
собрана: охват + финальный документ). Идемпотентность — ключ
`stage_results: "s5_assembly"` (та же формула
`sha256(input_hash | glossary_hash | level | cefr)`, что у S1–S4).

Сборка (ТЗ S5.1) — ДОПОЛНЕНИЕ `target.epub`, а не построение с нуля:
распаковка → у каждой главы с артефактами — ОТДЕЛЬНЫЕ XHTML-секции в
КОНЦЕ `<body>` (смешивание с оригинальным текстом запрещено; порядок
фиксирован: summary, vocab, expressions, grammar, questions,
exercises; секция — `<section class="s5-section"
id="s5-{type}-{chapter_id}">` + h2) → правка OPF (manifest/spine +
`study-answers.xhtml`), nav (EPUB3: плоские записи `<li>` на каждую
секцию + финальный документ; NCX: защитные `navPoint` c
`playOrder`=max+1) → упаковка в `learning.epub`: оригинальные записи
сохраняют имя, ПОРЯДОК и время; `mimetype` — ПЕРВАЯ запись, без
сжатия (STORED), остальные DEFLATED; финальный документ «Ответы и
охват» дописан в конец (фиксированная дата записи 1980-01-01 —
детерминизм перезаписи).

Отсечение ответов (T-S5-5): «Ответ:» — только в финальном документе
(mc — текст правильного варианта, tf — Верно/Неверно, gap/
translation/free — эталон); в телах глав — 0 вхождений. Состав
секций книги — эквивалентность «артефакт ⇔ секция» по каждой главе
(T-S5-11: секция есть ⇔ артефакт главы есть).

Охват (ТЗ S5.8 / E6): единственный источник —
`jobs.alignment_coverage` (`None` → AppError: E6 не исполнен);
расхождение с `alignment_report.json` > 1e-9 → AppError (стадия не
выпускает книгу). В книге — блок `data-s5-coverage/
data-s5-aligned/data-s5-total` + перечень пропущенных глав (0
выровненных сегментов). Искусственные 90% (T-S5-12) отражаются
дословно: `data-s5-coverage="0.900000"`, «90.0%», пропущенная глава
в перечне, её документ — побайтово без секций, расхождение с E6 = 0.

Валидация (Rule 6): внутренняя структурная ПЕРЕД атомарной выдачей —
`validate_study_book` (mimetype первой; записи target, кроме
структурных, побайтово; оригинальные блоки глав — точный префикс;
«Ответ:» в главах — 0; якоря секций на месте; записи TOC на все
якоря; OPF manifest/spine; охват в финальном документе) + EPUBCheck
(FATAL/ERROR → отказ, целевой файл не изменяется, Rule 6 fail
closed).

Атомарная выдача (Rule 8, тот же `atomic_finalize`, что E5/L3):
`learning.epub.partial` → fsync → внутренняя валидация → EPUBCheck →
`.bak-<stamp>` существующего (E5.9) → `os.replace` → fsync каталога.
Принятый `learning.epub` появляется только валидным; kill -9 в окне
записи оставляет либо отсутствие, либо валидный файл (T-S5-9 ×10);
in-process повтор сборки — побайтово тот же файл (детерминизм).

Экспорт карточек (ТЗ S5.6 — свой формат не изобретать): CSV — RFC 4180
(модуль `csv`), заголовок = полный фиксированный набор колонок языка
(общие 10 + свойства `card_schema.json`; вложенные объекты —
подстолбцы `имя_поле`); Anki — текст-импорт Anki (`#separator:Tab`,
`#html:false`, `#columns:Front/Back/<языковые>/Tags`, C-escaping
`\`, `\n`, `\t`), Front=word_form, Back=translation, теги
`epubtranslator pos=… cefr=… band=… chapter=…`; JSON — полный массив
объектов карточек (без потерь). Обязательные колонки — в 100% строк
(S5-6: `required_cells` схемы: артикль de/nl, род fr/it,
`main_forms` de, nullable-поля — колонка на месте, значение может
быть пустым). Anki/pyanki в окружении отсутствуют → фактический
импорт НЕ проводился (S5-7 — честный BLOCKER), формат верифицирован
структурно (служебные строки, число полей, теги — verbatim).

Отчёт: `s5_report.json` (stage, coverage, aligned/total,
chapters_total/chapters_with_sections, skipped
`[{chapter_id, title}]`, `sections: {ch: [типы]}`, exports
`{cards, csv, anki, json}`, epub `{entries_total, answers, nav, ncx,
epubcheck {version, available, errors, warnings,
unavailable_reason}}`, **zipinfo verbatim**, glossary_hash,
idempotency_key, timestamp). `quality.json` → секция `s5`
(`enabled`, coverage, главы, skipped, exports, `report`) + warnings
(пропущенные главы, частичный охват, EPUBCheck недоступен — Rule 6).
