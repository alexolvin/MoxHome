заявлялась). Владелец предоставил реальный OpenAI-совместимый эндпоинт (vLLM,

(`python -m app.cli translate … --wait`) + БД заданий + артефакты задания;

(Rule 7): задача фазы — показать, что полный цикл работает на реальном LLM и что
детерминированный контроль качества честно фиксирует реальные (модельные)
несоответствия, не ослабляя порогов.

Ограничения среды (честно): реальная модель `qwen3.8-27b` — thinking: без

GPU используется совместно (эндпоинт общий с кодом-агентом) — длительности
вызовов не воспроизводимы между прогонами; токены/статусы — ground truth из БД.
