## Протокол фазы (время — UTC; `date -u`)

- 2026-09-28 — ветка `stage/mtpe-M3` с `main` (после merge M2 `91693e7`).
- **Кодек** (`app/mtpe/markup.py`, §4.7): замена на уровне строки (сохраняет байты
  тегов, не пере-сериализует дерево) — гарантирует побайтовую обратимость. Парные
  элементы → `⟦n⟧…⟦/n⟧`, пустые (`br`, `img`, void) → `⟦n/⟧`; карта `n → (open, close)`
  с сегментом; восстановление только из карты (модель не пишет теги/атрибуты). Литеральные
  `⟦`/`⟧` → U+E000/U+E001. `src_plain` — текст без маркеров, `br` → `\n` (вход черновика).
- **Транспорт** (`app/llm/mt.py`, §4.9): вторая ветвь того же клиента `app/llm/`
  (второго клиента нет): `POST {base_url}/completions`, поле `prompt` (заполненный
  `mt_draft`); ответ `choices[0].text` + `finish_reason` + `usage`. Прогрев §4.6 —
  `max_tokens: 1`, `warmup_timeout_s`. Повторы — только транспортные (таймаут, 5xx, обрыв);
  4xx/не-JSON — стоп (content-повтор при `temperature:0` запрещён). Поле `model` каждого
  ответа сверяется с моделью снимка → `model_mismatch` — остановка. Токены — в учёт
  `profile=mt` (`_UsageAccumulator`), сырой запрос/ответ — в `raw/`.
- **Фаза** (`app/mtpe/draft.py`, §7): состав сегментов — общая `read_epub` (тракт A,
  копии нет). Без букв → `passthrough` (`draft=src_plain`, в LLM не шлётся). Строки по
  `\n` — отдельные запросы, черновик через `\n`; длинная строка (>`max_segment_tokens`) —
  по предложениям L1 исходного (spaCy), склейка пробелом, число частей в `split`.
  `max_tokens = ceil(src_tokens×max_tokens_ratio)+32`. Ключ идемпотентности §4.8
  (`sha256(src_plain∥model∥prompt_task∥fingerprint∥"src>tgt")`); возобновление — по ключу.
  Флаг `draft_bad` (§7 п.9): пустой / содержит `Translate this from` / строка
  `«mt_name»:»` / `finish_reason=length` / язык ≠ целевой (сегменты ≥ `lang_check_min_words`,
  детектор, seed 0). Запись в `drafts.jsonl` сразу после черновика, `fsync`.
- **Схема/репо:** `tokens_mt` (колонка + миграция + инвариант E4-5: `total = перевод+fill+
  analysis+mt`); `add_profile_tokens` принимает `mt`; `set_phase` (M6, колонка `phase` уже
  в схеме M1). Задание в БД фазой не создаётся: `add_tokens` без задачи — no-op (0 строк),
  `add_profile_tokens` — в `job_tokens` (без FK) — `job_id` = строка, `settings.job_dir`.
- Тесты: `tests/test_mtpe_m3.py` (9 функций / 11 кейсов: M3-1…M3-9, M3-7 ×3 сценария),
  mock `/v1/completions` + `_mt_response` (окружение: 5 профилей, mt → mock, `run_book`
