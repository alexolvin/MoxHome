# CONTROL — S3: грамматические заметки

**Дата:** 2026-09-13 · **Ветка/PR:** `stage/S3` → `main`

Метод: подстадия `s3_grammar` стадии `LEARNING` (ТЗ_03, после S2) — материалы
строятся по тексту языка-ИСТОЧНИКА (пары E6, как S1/S2). Гейт уровней
(ТЗ_03, таблица): S3 входит в `Learning`/`Intensive` (`SUBSTAGE_LEVELS`,
данные `app/learning/__init__.py`); на `Minimal`/`Balanced` подстадия не
исполняется и артефактов не выпускает. Идемпотентность — собственный ключ
`stage_results: "s3_grammar" = sha256(input_hash | glossary_hash | level |
cefr)` (та же формула, что у `s1_vocabulary`/`s2_mwe`).

Детерминированный предотбор — тот же движок, что у S2 (Rule 8: один механизм
`select_mwe_candidates`, `app/learning/mwe.py`), со СКОПОМ подстадии: поле
`stages` таксономии (данные, `for_stage(phenomena, "s3")`; `stages` обязано
идти ВМЕСТЕ с `patterns` — иначе новый шаблон молча попадёт в чужую
подстадию, Rule 6: опечатка не отключает/включает шаблон молча). Для S3
добавлен тип шаблона `token` (`TokenCriterion`: И заданных полей `pos` /
`text` / `mood` / `tense` / `aspect` / `position`) — морфологические
признаки spaCy, как просит ТЗ_03 S3.5 (наклонение, время, вид; модальные
частицы — точные словоформы); wrap-маркеры расширены теми же морфологическими
признаками (DE-NEBENSATZ-VERBLETZT: `start` dass/weil/wenn/als/ob/obwohl,
`end` VERB/AUX, `end_final`). LLM — задача `grammar_note`
(`prompts/grammar_note/v1.yaml`, `pair_required=false`), по главам батчами
`limits.grammar_llm_batch` (25), никогда не вся книга (ТЗ общее требование
5); модель ТОЛЬКО объясняет найденное (S3.5: выдвижение списка запрещено —
эхо `surface` одного кандидата на заметку). Лимит ≤K на главу
(`_s3_split_candidates`): топ-K на главу по (−вхождения, id, поверхность) —
приоритет = повторяемость в книге (K — конфиг
`limits.grammar_max_notes_per_chapter`, дефолт 10); не отобранные —
`not_selected` с фактическим счётом в отчёте. «Объяснить один раз» (S3.4):
первый отобранный кандидат явления (порядок книги) — развёрнуто (LLM);
остальные — краткая ДЕТЕРМИНИРОВАННАЯ ссылка «Повторение: см. первую заметку
об этом явлении.» (`reference_to` = segment_id первой заметки; 64-символьный
hex-id в текст НЕ встраивается — langdetect сдвигает русскую фразу с таким id
на bg, измерено; версия/модель ссылки пусты — LLM не участвует). Развёрнутая
первая отклонена — ссылающиеся заметки отклоняются сами («ссылка
некорректна»). Перед выпуском — 5-пунктная детерминированная валидация
(`check_grammar_notes`, `app/learning/grammar.py`): 1) id явления ∈
таксономии языка-источника (S3-1); 2) поверхность — среди детерминированных
кандидатов («подброшенная» отклоняется, механизм S1.5/S2.6); 3) цитируемый
фрагмент (surface) — в указанном сегменте (`contains_form`, Rule 8; S3-2);
4) пояснение непустое и длина ≤ `limits.grammar_note_max_chars` (300) —
превышение ОТКЛОНЯЕТСЯ, а не усекается молча (S3.1, T-S3-10); 5) язык
пояснения = целевой (langdetect с фиксированным сидом из конфига —
детерминированно; S3-5). Отклонённые не исчезают: `grammar_notes.json` →
`rejected` с причинами + предупреждение в `quality.json`. Дедупликация
LLM-ответа по `surface.casefold()` (механизм S1.2/S2.4). Запись (ТЗ_03 общие
требования 1–2): `phenomenon_id`, `surface`, `segment_id`, `chapter_id`,
`explanation`, `note_type` (detailed/reference), `reference_to`,
`occurrences`, `example_sentence`, `source_text_hash`,
`source_language`/`target_language`, `user_level`/`user_cefr`,
`glossary_hash`, `prompt_file`/`prompt_version`, `model`, `profile`,
`timestamp`. `quality.json` → секция `s3`: `enabled`, `book_words`,
`candidates_total`, `notes_issued`, `notes_rejected`,
`notes_not_selected`, `detailed_notes`, `reference_notes`,
`max_notes_per_chapter`, `per_chapter`, версии, `report`. Полнота (S3-6) —
на golden-наборах `config/languages/*/grammar_golden.yaml` (20–31
предложений/язык) по ПРЕДОТБОРУ: сопоставление пар (предложение, id явления);
гейтится RECALL ≥ 0.75 (precision — не гейтится: дополнительные кандидаты
допустимы, например EN-PERFECT ⊂ EN-MODAL-PERFECT/EN-COND-3). LLM —
mock-сервер (D3, эхо кандидатов + ротация; сценарии `grammar_bad_id` —
инъекция id вне таксономии, `grammar_bad_quote` — инъекция surface вне
кандидатов); реальные LLM-прогоны не проводились (BLOCKER-1). Прогон —
`python tests/s3_evidence.py`, тесты — `pytest tests/test_s3_grammar.py`
(21 запуск: T-S3-1…T-S3-10, из них T-S3-6 ×5 и T-S3-7 ×5 языков).
Verbatim-захваты: `docs/CONTROL/evidence/S3/s3-1…s3-7.txt`.

## Метрики и механизмы (измерено vs не проверено)

**Измерено** (артефакты в колонке «Артефакт»):
- 0 принятых с id вне таксономии; отклонение с причиной — S3-1;
- 0 заметок с цитатой вне сегмента; подброшенная заметка отклонена — S3-2;
- ≤K на главу (16 кандидатов → 10 выпущенных, 6 `not_selected` записаны) — S3-3;
- 0 повторных развёрнутых объяснений (6 detailed + 4 reference, ссылки —
  детерминированно, LLM не участвует) — S3-4;
- 100% пояснений на целевом языке (10/10 ru) — S3-5;
- recall 1.000 на всех 5 языках (95 golden-пар) ≥ 0.75 — S3-6;
- 5/5 исходных языков до LEARNING с метриками S3 + гейт уровней — S3-7.
- Тесты: 223/223 (202 + 21 запуск T-S3-1…T-S3-10), ruff 0, mypy 0 (63 файла).

**Не проверено / ограничения (честно):**
- LLM-объяснение — mock (D3): реальные LLM-прогоны не проводились
  (BLOCKER-1). Реальные механизмы: детерминированный предотбор (шаблоны
  `token`/`wrap` + морфология + повторяемость), лимит ≤K на главу,
  «объяснить один раз» + ссылки, 5-пунктная валидация, дедупликация,
  метрики golden, отчётность; mock — детерминированный эхо + сценарии
  `grammar_bad_id`/`grammar_bad_quote`.
- DE-NEBENSATZ-VERBLETZT: шаблон (`wrap` start=dass/weil/wenn/als/ob/obwohl,
  end=VERB/AUX, `end_final`) покрывает придаточное в КОНЦЕ предложения;
  придаточное в середине предложения («Er, der den Zug verpasst hat, …»)
  шаблон не находит — честный предел (зафиксировано в `de/phenomena.yaml`).
- Приоритет по уровню пользователя (ТЗ_03 S3.3: «явления, соответствующие
  уровню пользователя») не реализован: в таксономии `phenomena.yaml`
  грамматическим явлениям CEFR-уровень не заведён — приоритет = только
  повторяемость в книге (честный предел; поле таксономии для уровней —
  за L1-форматом, расширение данных, не кода).
- EN-PERFECT ⊂ EN-MODAL-PERFECT/EN-COND-3: формы «must have forgotten»/
  «would have come» дополнительно кандидатируют как EN-PERFECT (precision
  справочно 0.786) — гейтится только RECALL, дополнительные кандидаты
  допустимы (качество описания — за LLM, mock).
- IT-CONGIUNTIVO — по морфологическому признаку модели (Mood=Subjunctive;
  «venga» размечается стабильно — измерено на фикстуре T-S3-9);
  FR-SUBJONCTIF — по списку словоформ (fr_core_news_sm теггер слаб —
  измерено на L1): морфологии subjunctive во fr-модели нет — честный предел
  данных модели.
- Малые S3-фикстуры (fr/it — 1 кандидат) — метрики записаны, выпускаются
  реальные заметки (1/1); полнота по явлению на таких фикстурах не
  интерпретируется (S3-6 — отдельный прогон по golden-наборам).
- no-op (learning не включён) и гейт уровней покрыт T-S3-7 (Minimal — ни S1,
  ни S3; Balanced — S1 без S3; Learning — все) и воркер-тестами E3.
