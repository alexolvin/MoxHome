# CONTROL — U3: Переработка Web UI

**Дата:** 2026-09-17 · **Ветка/PR:** `stage/U3` → `main`

Метод: `tests/u3_evidence.py` (14 проверок) — httpx TestClient на
реальном приложении (in-process) + реальные воркер-процессы (uvicorn,
`--loop`) + lxml по отрендеренному HTML всех 7 страниц + статический
парсинг `static/style.css` + прямой доступ к SQLite + MockLLMServer +
реальные CLI-subprocess'ы (регрессия U2). Verbatim-захваты:
`docs/CONTROL/evidence/U3/`. Браузерная автоматизация в CONTROL не
вводится (TZ_04 §U3 §11): все критерии сформулированы измеримо без
браузера. Визуальная Playwright-проверка (mobile 360/412 + desktop
1280, `channel="chrome"`) — отдельный контроль стадии, протокол —
`.a/reports/u3_browser/`.

Содержание стадии (три пробела живого стенда):
1. **Удаление заданий + очистка логов + массовая очистка.**
   `DELETE /api/jobs/{id}` — строки `jobs`/`transitions`/`job_tokens`/
   `stage_results` одной транзакцией, каталог `Settings.job_dir(job_id)`
   — после успешного коммита; задание не в терминальном статусе → `409`
   + причина verbatim, данные не изменяются; путь каталога
   проверяется `is_relative_to(storage.root)` (D93).
   `POST /api/jobs/purge` — два шага: dry-run (перечень) →
   `confirm_token` (удаление); только терминальные задания старше
   `ui.purge_min_age_days`, опциональные фильтры книга/пара.
   `POST /api/jobs/{id}/logs/clear` — `job.log` + `errors.log` =
   0 байт + строка факта усечения; `quality.log` отдельной операцией
   не усекается (D92 — доказательная база L3/V1.8a).
2. **Версионирование промптов из интерфейса.**
   `POST /api/prompts/versions` — создаётся только `v(N+1)`; перезапись
   `vN` запрещена (D90); валидация ДО записи (невалидный YAML /
   отсутствующее обязательное поле / неизвестная задача → `400`,
   созданных файлов 0, LLM-запросов 0); резолвер выбирает `N+1`,
   `resolved_prompts` фиксирует `N+1`.
3. **Мобильная вёрстка.** Mobile-first: под `ui.mobile_breakpoint_px`
   (640 px) каждая таблица рендерится карточным списком с тем же
   набором полей (число полей карточки == числу столбцов, порядок
   сохраняется — скрытие столбцов запрещено); горизонтальной
   прокрутки `body` нет; навигация — одна строка, текущий раздел —
   `aria-current="page"`.

Собственной бизнес-логики нет (Rule 8): значения интерфейса — из
единственных источников `views.py`/`progress_facts`/`languages_view`;
мутации — через `JobRepository` (единственный писатель БД) и
существующий резолвер промптов. Все строки интерфейса — в одном
словаре `app/web/strings.py` (плоский словарь); статусы заданий, коды
языков, имена задач и причины отказов НЕ переводятся — verbatim как в
БД (U3-1, U3-12; аудит V1.4 расширяется на словарь
`<script id="u3-strings">`). Мутирующие маршруты fail-closed: пустой
`SERVER_AUTH_SECRET` → `403` (D91); CSRF — stateless HMAC-токен
(заголовок `X-U3-CSRF`). Цвета/отступы/типографика — CSS-переменные
`:root`; числовых цветов вне `:root` — 0 (U3-3).

Прогон: `python tests/u3_evidence.py` (полный прогон ≈ 65 s), тесты —
`pytest tests/test_u3_web.py` (T-U3-1…T-U3-15). Регрессия U1 (10) + U2
(4) на коде U3 — U3-13.
