# Правила проекта EpubTranslator

## Расположение файлов агента
- Все файлы, относящиеся к взаимодействию с кодовым агентом, хранятся ТОЛЬКО в папке `.a/`:
  - `.a/tasks/` — файлы задач;
  - `.a/handoff/` — документы передачи (handoff);
  - `.a/reports/` — отчёты.
- Не создавать артефакты агента (черновики, отчёты, рабочие заметки) в корне проекта и в других каталогах кода.

## Git
- Все папки, начинающиеся с точки (включая `.a/`), исключены из коммита маской в `.gitignore` — маска обязательна, не удалять.
- Точечные папки не добавлять в индекс (даже через `git add -f` без явной необходимости).
